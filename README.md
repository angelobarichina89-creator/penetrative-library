# 📚 Penetrative Library
Library & Digital Asset Management System


## 📋 Project Description
A complete library management system that manages physical books, digital media, member subscriptions, fines, and borrowing logs.

## ✨ Features
- 📖 View, Search & Filter Books
- ➕ Add / Edit / Delete Books
- 👤 Register Students / Users
- 📤 Borrow & Return Books
- ✅ Show Book Availability
- 📊 Admin Dashboard
- ⏰ Overdue Detection
- 🤖 AI Book Recommendations
- 🌙 Dark Mode

## 🛠️ Tech Stack
- *Backend:* Node.js, Express, MySQL
- *Frontend:* HTML, CSS, JavaScript
- *Database:* MySQL
